# ARGO Warehouse

Компактная внутренняя система учёта оборудования ARGO Media.

## Что входит в продукт

- каталог оборудования с поиском, фильтрацией и постраничной загрузкой;
- карточка каждой единицы или группы оборудования;
- списки комплектации в режимах «по единицам» и «по количеству»;
- авторизация сотрудников через Supabase Auth;
- подготовка печатного Excel-документа и полной технической детализации.

События, точки монтажа, отчёты, управление ролями и демонстрационный UI Kit из старой версии не входят в новый продукт.

## Технологии

- React 19 + TypeScript;
- Vite;
- Supabase Database и Auth;
- собственная дизайн-система с фирменным красным акцентом ARGO.

## Локальный запуск

```bash
npm install
cp .env.example .env
npm run dev
```

В `.env` нужны адрес проекта и публичный ключ Supabase. Реальный `.env` не должен попадать в Git.

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-publishable-or-anon-key
```

## Проверка

```bash
npm run build
npm audit
```

## Изображения и кеш

- каталог содержит 176 оптимизированных WebP для 217 уникальных моделей; для 41 неоднозначной или обобщённой позиции используется иконка категории;
- источники изображений сохранены в `public/equipment-images/manifest.json`, полный отчёт — в `public/equipment-images/report.json`;
- повторный поиск и оптимизация запускаются командой `npm run images:equipment` (на macOS используются `sips` и `cwebp`);
- страницы оборудования и списков кешируются в браузере на 10 минут, справочник категорий — на 24 часа; после записи соответствующий кеш сбрасывается автоматически.

## Статус переработки

Новый интерфейс читает существующие данные и умеет создавать оборудование и списки. Редактирование и удаление исторических записей пока отключены до нормализации статусов и отдельной проверки RLS-политик. Старую версию по-прежнему можно открыть в ветке `main`.
