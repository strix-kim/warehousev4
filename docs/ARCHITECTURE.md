# Архитектура — указатель

Этот файл больше не описывает архитектуру. До сессии 1 он описывал Vue-версию продукта
(`src/app/router/`, Atomic Design в `src/shared/ui/`) — структуру, которой в проекте нет
с момента переписывания на React.

**Устройство кода читается из самого кода:** `src/react` — 45 файлов, ~8 тыс. строк,
слоёв три (`app/` каркас, `features/<фича>/` страница плюс её api, `lib/` +
`components/` общее). Пересказа этой структуры в доке намеренно нет: он обязан
разойтись с кодом, а грепом по `src/react` она читается быстрее.

Библия — три страницы, и в них лежит только то, чего в коде нет:

| Страница | О чём |
|---|---|
| `docs/project/01-product.md` | что за продукт, для кого, **чего в нём принципиально НЕТ** |
| `docs/project/02-decisions.md` | решения, которые не выводятся из кода: почему так, где грабли, что сломается |
| `docs/project/03-data-model.md` | схема, RLS, правила миграций — она живёт вне git |

«Как есть сейчас» (числа, долги, очередь) — `docs/project/current-state.md`.
Хроника и «почему решили» — `docs/handoffs/`. Как ведётся проект —
`docs/system/workflow.md`. Правила для агентов — `CLAUDE.md` и зеркало `AGENTS.md`.

Файл оставлен указателем, а не удалён: на него могут ссылаться внешние заметки.
Дублировать сюда содержание библии нельзя — один источник правды на сущность.
