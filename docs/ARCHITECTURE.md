# Архитектура — указатель

Этот файл больше не описывает архитектуру. До сессии 1 он описывал Vue-версию
продукта (`src/app/router/`, `src/app/plugins/`, Atomic Design в `src/shared/ui/`) —
структуру, которой в проекте нет с момента переписывания на React.

**Актуальная архитектура — `docs/project/04-architecture.md`.**

Остальная библия:

| Страница | О чём |
|---|---|
| `docs/project/01-product.md` | что за продукт, для кого, что НЕ входит |
| `docs/project/02-features.md` | функции: что решает база, что показывает клиент |
| `docs/project/03-data-model.md` | таблицы, RLS, миграции |
| `docs/project/04-architecture.md` | структура кода, маршруты, слой данных, кэш, сборка |
| `docs/project/05-roadmap.md` | вехи в порядке зависимостей |
| `docs/project/06-design-system.md` | токены, палитра, брейкпоинты |

Как ведётся проект — `docs/system/workflow.md`. Правила для агентов — `CLAUDE.md`
и парное зеркало `AGENTS.md`.

Файл оставлен указателем, а не удалён: на него могут ссылаться внешние заметки.
Дублировать сюда содержание библии нельзя — один источник правды на сущность.
