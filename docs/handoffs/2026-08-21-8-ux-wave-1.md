## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Кнопки шапки редактора ломаются по словам при узком окне | средняя колонка грида (`1fr`) не сжимается ниже min-content строки статуса с `nowrap`, отжимает колонку `auto` | `.editor-header > div { min-width: 0 }`, имя с `text-overflow: ellipsis`, кнопкам `white-space: nowrap` |
| Попап подкатегорий закрывается при прокрутке внутри себя | `usePopoverLayer` слушает `scroll` в capture на window и закрывает на любой, включая собственный список | игнорировать события, чей `target` внутри `insideRefs` |
| Флаг «запрос отказал» через `.catch` мёртв | `cachedQuery` при живой записи подменяет провал последним значением и РЕЗОЛВИТСЯ | признак отказа — несдвинувшаяся метка `touchedAt` до/после запроса (кэш обновляет её только на успехе) |
| Справочник таксономии с `.order('type')` терял бы последнюю категорию | Data API режет ответ на 1000 строк; с сортировкой обрезка становится ровной по категории | читать батчами по 1000 с полным порядком `type, subtype, id` — идиома `fetchAllEquipment` |
| Набор «12» поверх «5» в поле количества резал выбранные S/N до одного | посимвольное применение проходило через `count = 1` | коммит значения на blur/Enter; клик по кнопке сначала снимает фокус, так что экспорт видит зафиксированное число |
| iCloud-двойник «… 2.md» отличается от оригинала | синхронизация воскрешает не только копии, но и промежуточные ревизии | `cmp` по ревизиям `git log -- путь`; совпал с прошлым коммитом → удалить |
| Прораб: «постоянно просишь разрешения» | пауза «выполню следующим ходом» после показа `UPDATE` + всплывающие запросы инструментов | правило 8 — предупредить и исполнить тем же ходом; allowlist в проектном `.claude/settings.json`; память `no-permission-pauses` |
| Скилл `deploy-verify` утверждал «мост не подключён» | текст написан до с2 и не обновлён | абзац исправлен в этом закрытии |
