## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Имена на ТВ резались снизу при 9 позициях | вертикальный паддинг клетки .45em + две строки > высоты строки | паддинг .15em, центрирование `safe center`, имя `flex: 0 0 auto` |
| `scrollWidth`/`clientWidth` показывал запас 0 у всех подписей | flex-элементы шириной по содержимому | запас мерить Range: правый край текста против контентного края контейнера |
| Пунктир «Наём» 1.5px рисуется 1px | Chrome округляет толщину рамки до целого | принято, не баг правила |
| Сообщение агенту «встало в очередь» и не дошло | агент уже завершался | проверять файлы по факту, при нужде слать повторно |
| Линии клеток бледнели на бумаге | новые линии на `--line-2` | на печати `--line-2` = `--line` |
