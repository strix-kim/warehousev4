## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Прямой `delete from storage.objects` мостом → 42501 | `storage.protect_delete()`: только Storage API | временная DELETE-политика на точный путь + curl, политику снести тем же ходом |
| «~190 сотрудников» оказались 12 | колонка А xlsx — номера внешнего реестра (184, 199…), не счётчик строк | количество = строки с ФИО, а не максимум номера |
| Даты в xlsx и docx противоречат | xlsx ведёт М.Д.ГГГГ (05.19.1973), docx — Д.М.ГГГГ | арбитр — сам ПИНФЛ: цифры 2–7 кодируют дату рождения; неоднозначные даты выдачи взяты как ДД/ММ (локальный порядок) |
| Фоновые агенты гибнут молча | Esc прораба прерывает и агентов; статус — только в meta.json задачи | после Esc проверять `stoppedByUser`, остановленного не реанимировать — перезапуск |
| Двойники «имя 2.ext» на новых файлах | iCloud-синхронизация (§10) — на этот раз в НОВОМ каталоге фичи | ритуал прежний: `git status` перед add, `diff -q`, удаление явным списком |
