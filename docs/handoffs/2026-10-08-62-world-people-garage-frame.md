## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Камера встаёт не на расчётную дистанцию | `a.sub(b).setLength(a.distanceTo(b))` — методы three правят вектор на месте, аргумент считается уже по изменённому | длину брать до цепочки либо из готового числа |
| Гипотеза «не тот аспект» держалась сессию | число совпало с расчётом под аспект 1 случайно | сначала вывести живые значения (`console.info` + scout), потом строить модель |
| Название обещает больше кода | «гараж изнутри», `?in=`, `inside` — а это подводка снаружи | слова прораба сверять с тем, что он УВИДИТ, до кода; чекпоинт плана формулировать картинкой, не механизмом |
| Scout: «двигаются 5, а не 3» | замер по чипам ловит и сдвиг раскладки подписей | движение фигурок мерить не по DOM-чипам либо вычитать шаг раскладки |
| `git commit -a` | хук харнеса запрещает | `git add` поимённо |
