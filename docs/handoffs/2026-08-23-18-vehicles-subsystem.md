## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Тест кириллического дубля «01 439 СНА» прошёл вставкой | «СНА» кириллицей — двойник «CHA», не «SNA»: у S и N кириллических близнецов нет — ошибка теста, не схемы | тестировать двойники на буквах, у которых они есть: «01 Т 769 МС» → 23505 |
| Телефоны сотрудников пусты у всех 12 | в xlsx с17 колонки телефона не было; вскрылось встраиванием телефона в карточку машины | дописаны шестерым из автомобильного xlsx; остальные — руками через правку карточки |
| Пачечный upsert связки отлетал бы по RLS | postgrest-js по умолчанию шлёт NULL в непереданные колонки — `created_by = NULL` ≠ `auth.uid()` | `defaultToNull: false` (`Prefer: missing=default`) в `saveVehicleDrivers` |
| Выпадашка водителей схлопывалась бы на телефоне | `usePopoverLayer` закрывается по `resize`, а виртуальная клавиатура даёт `resize` сразу после фокуса | панель в потоке формы + закрытие по уходу фокуса, `mousedown` в панели гасится (Safari снимает фокус до click) |
