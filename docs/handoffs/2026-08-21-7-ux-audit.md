# Handoff: 2026-08-21 (сессия 7) — UX-аудит сценариев

Цель сессии была перебита прорабом на старте: вместо очередного `/doc-audit` —
**UX-аудит сценариев продукта** с упором на создание списка и на то, «где что
вписывать». Уточнения по ходу: главная платформа — **компьютер**, телефон и
планшет вторичны; «телевизор» в офисе — это **зеркало ноутбука сотрудника**, а не
отдельный экран (выяснено в конце, после съёмки 1920×1080).

Раскладка тиров: четыре аудитора по сценариям — Opus; адверсариальная сверка,
синтез и отчёт — Fable (сессия). `scout` не понадобился: проверки делал сам
grep'ом и `SELECT`-ами. Воркфлоу не запускался — четыре параллельных агента.

## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| На полностраничных снимках правая панель редактора полупрозрачна, на десктопе и на 1920 | `fullPage` у Playwright пересобирает вьюпорт, а высота `.editor-grid` завязана на `100dvh`; кадр ловит анимацию `rise-in` заново | не верить `fullPage` для анимированных блоков: замерять `getComputedStyle().opacity` и снимать `--fold` после паузы; находка снята до отчёта |
| Бейдж количества на кнопке «+» «переносится на вторую строку» | hover-эффект `rotate(90deg)` на всей кнопке; после тапа/клика hover залипает | две независимые правки в U10: ширина колонки на десктопе + вращать только иконку под `@media (hover: hover)` |
| Публикация артефакта падает `deploy 400: invalid or unpaired escape sequences` | в тексте находки лежал литерал U+FFFD из битой строки прода | в артефактах писать «U+FFFD» словами; в md-отчётах литерал допустим |
| `UPDATE … RETURNING` в CTE, а контрольные `count(*)` в том же запросе показывают старое | подзапросы видят снимок до модификации в той же команде | проверять результат отдельным `SELECT` после |
| Прораб ждёт «как в другом проекте», а закрытие здесь долгое | протокол закрытия этого проекта тяжелее: handoff + перезапись current-state + decisions + патчи библии + слияние + сверка выкатки | это устройство, не сбой; сессии без правок кода закрываются быстрее (библию патчить нечего) |
| Чужой вывод съёмки мог уехать в репозиторий с `git add -A` | iCloud-двойники и scratchpad рядом | `git add` явным списком (gotchas §10) — соблюдено |
