## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Новый арт «меньше» соседнего при той же ширине 1440 | Шире 1500 у «Сотрудников» 82%, у новых 54%; люди в рост кажутся крупнее предметов | Масса арта — по замеру на 3–4 ширинах; для предметов во весь кадр — длиннее растворение под текстом |
| Декоративный круг поверх картинки | `::after` без `z-index` на слое арта, но позже по дереву | Явные слои: круг 0, арт 1, текст 2 |
| Правило скрытия не срабатывает (подвал редактора, «Залы» в таб-баре) | Двухклассовое/тег+класс общее правило бьёт одноклассовый модификатор | Канон с26 «грепай все правила селектора» подтверждён в третий раз |
| `Math.ceil` даёт на 1 больше Excel | Сумма дробных длин: 125,00000000000003 → 28,000…04 | Округление до 9 знаков перед `ceil`; тест с контролем чувствительности |
| `setSearchParams` пишет `l=15%2C50` | Кодирует запятую | `navigate({ search })` строкой |
| Хук `session-start` на закрытии кричит «указатель на несуществующий файл» | Current-state переписан раньше handoff | Нормально в середине закрытия; порядок скилла — номер → handoff → указатель |
| Незакоммиченные правки при чистом закрытии прошлой сессии | Утренняя сессия оборвалась, живой процесс `claude` 11:42 висел рядом | Спросить прораба, чьё; здесь — его слово «наше» |
