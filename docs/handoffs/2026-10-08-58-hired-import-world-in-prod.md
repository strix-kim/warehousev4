## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Ведущий сам гонял Playwright по `/world` | переход к новой подзадаче «по инерции» | стоп-проверка перед первым вызовом браузера/SQL/скрипта: это бриф `scout` (память `machine-checks-via-sonnet`, второе замечание прораба) |
| «Мир в проде», а прораб открыл сайт и ничего не увидел | выкатили маршрут и пункт меню, главная не менялась; SPA держит старый бандл до перезагрузки | говорить прямо, ГДЕ лежит новое и что нужна перезагрузка вкладки; «в проде» ≠ «на первом экране» |
| `git add <каталог>` отклонён хуком | хук не даёт забрать неотслеживаемые файлы оптом | добавлять поимённо, сверяя новые файлы с отчётом кодера |
| В консоли «change in the order of Hooks … WorldStage» | HMR dev-сервера в момент правки файла кодером | не баг продукта: на прод-сборке чисто; проверки перед выкаткой — только на `vite preview`, не на 5180 |
| `browser_take_screenshot` пишет в корень репозитория | MCP не пишет вне корня проекта | в брифе scout: `page.screenshot({ path })` через `browser_run_code_unsafe` в scratchpad |
| Кодер считал раскладку чипов скриптом с оценочными ширинами | браузер был занят другим агентом | цифрам расчёта не верить до замера scout по `getBoundingClientRect` |
