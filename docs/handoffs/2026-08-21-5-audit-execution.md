# Handoff: 2026-08-21 (сессия 5) — аудит выполнен целиком

Цель, заданная прорабом: **«выполнить всё из проведённого аудита»**. Выполнено:
все 6 шагов «Порядка работ» и все 44 строки таблицы находок закрыты за одну сессию
(аудит закладывал шесть). Сессия пережила обрыв лимита API посередине и смену суток.

синтез; Opus (`coder`) — вся реализация (9 прогонов); Sonnet не понадобился —
механики без интеллекта в сессии не было.

## Проверка

- Каждый шаг: `npx tsc -b --force` и `npm run build` зелёные; коммит на шаг.
- Живое тело RPC перед заменой сверено с baseline (дрейфа кликами не было);
  после каждой миграции — контрольный SQL (защита локации, гранты, индекс,
  40001-ветка).
- Грабля грантов поймана контролем: default privileges Supabase выдали EXECUTE
  `anon` — снято догоняющей миграцией, правило в gotchas §3.
- Распилы и CSS — машинные доказательства эквивалентности (мультимножество тел;
  каскад в 5 диапазонах).
- **Превью-деплой проверен снаружи** (после того как прораб включил
  Preview-переменные): гейт env пройден, `npm ci` в логе, sourcemaps на месте,
  robots.txt отдаётся, пропавший чанк — честный 404. Подтверждён остаточный риск:
  `immutable` липнет и к 404 (принят до вехи 2, записан в backlog).
- Гейт env поймал реальную дыру: у Preview-окружения Vercel никогда не было
  `VITE_`-переменных — все прошлые превью веток собирались с нерабочим логином.

### НЕ проверено

- **Ни один сценарий не прогнан руками прораба.** Прораб принял работу, отложив
  ручной прогон («что можем — сам протестирую»). Чеклист приёмки жив:
  https://claude.ai/code/artifact/bc0f35b9-df9d-4148-bff0-e883ebe1ff85 —
  галочки сохраняются, гонять можно на проде после выкатки.
- **`/rls-verify` не запускался** — в проде один аккаунт (долг с с2). Пересозданная
  RPC сохранила проверку роли дословно (сверено по телу), но прогон под двумя
  аккаунтами остаётся обязательством при появлении второго пользователя.
- Автосейв черновика и оптимистическая блокировка проверены кодом и SQL, но не
  живым кликом.
- `baseline.sql` по-прежнему ни разу не исполнялся на чистой базе (долг с с2).

## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Worktree-агент отчитался про код, которого в ветке давно нет (bundle 358 КБ, живой `savedId`) | worktree-изоляция срезается с `main`, а не с HEAD ветки сессии | работа выброшена и переделана в основном дереве; правило в gotchas §13: сверять базу агента ДО ревью; CSS-блок с той же базы выжил законно — его файл ветка не трогала (проверено `git log -- файл`) |
| `anon` получил EXECUTE на новую функцию, хотя миграция делала `revoke from public` | default privileges Supabase выдают гранты новым функциям напрямую `anon`/`authenticated` | каждый `create/replace function` — с явным `revoke from public, anon` + контрольная выборка `routine_privileges`; gotchas §3 |
| Перенесённые git'ом файлы воскресли untracked-копиями (дважды: JSON в `public/`, `EquipmentVisual.tsx`) | служба синхронизации восстанавливает удалённое со старым mtime | `git status --short` перед каждым `git add -A`, сверка с `git show <commit>^:путь`, удалять; gotchas §10 |
| Оба превью ветки падали ERROR при зелёной локальной сборке | гейт env сработал в бою: у Preview-окружения Vercel не было `VITE_`-переменных вовсе — прежние превью молча собирались с нерабочим логином | переменные включены прорабом для Preview; редеплой прода ошибочно принятый за превью — распознан по `action: redeploy` + `target: production` |
| `clearListDraft` через `invalidateCachePrefix` отменял запись ВСЕХ летящих ответов | инвалидация поднимает глобальное поколение — чистка несуществующего черновика наказывала чужие запросы | ранний выход, если черновика нет; глобальные поколения оставлены осознанно (decisions) |
| `fatal: not a git repository` посреди закрытия | липкий cwd Bash: предыдущая команда сделала `cd` в scratchpad (грабля уже была в handoff с4) | абсолютные пути или `cd` в корень в той же команде — правило работает, но требует дисциплины в КАЖДОМ вызове |
| Обрыв обоих агентов на лимите API | лимит сессии истёк посреди параллельной волны | возобновление: агент с частичной работой разбужен `SendMessage` с картой состояния дерева, пустой worktree перезапущен свежим брифом; потерь нет |
