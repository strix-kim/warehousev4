| Симптом | Причина | Решение |
|---|---|---|
| `npm run dev` — «Port 5180 is already in use» | Vite этой папки уже работал с утра | `lsof -tiTCP:5180`, cwd процесса = репо → пользоваться им |
| Два агента задели бы один CSS | `06-responsive.css` смешивал оболочку, каталог и редактор | до запуска — чистый перенос в файлы-владельцы; перенос доказывать `getComputedStyle`, не диффом (порядок меняется) |
| Правило `.app-shell--task .app-date-picker__popover` не срабатывало | поповер в портале на `body`, вне `.app-shell` | `body:has(.app-shell--task) …` |

| `npx tsc -b -p …` — TS5072 | у `-b` нет `-p` | `tsc -b` из корня |
