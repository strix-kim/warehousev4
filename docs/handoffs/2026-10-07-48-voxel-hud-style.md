## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Прораб открыл сравнение и увидел 404 в двух рамках | страницу сравнения выложил и дал ссылку до того, как кодеры создали файлы | ссылку на стенд давать только после сдачи всех его частей |
| Полосы прокрутки в рамках-iframe 390×560 | `border` при `border-box` съедает 2 px окна iframe | рамку iframe рисовать `outline`, не `border` |
| Кодеры HUD работали вслепую, пока браузер занят другим агентом | Playwright — единоличный ресурс | отдельный headless Chrome со своим `--user-data-dir`: `--headless=new --window-size=W,H --screenshot=файл URL`; сам не завершается — запускать в фоне и `kill -9` по PID через ~10 с |
| Красный круг выбора не показать на макете-снимке | подложка — PNG, круг лёг бы поверх здания | состояния мира показывать только на живой сцене (шаг 4) |
| Имя раздела не влезает в табличку 200×56 рядом с числом | «СКЛАД · ОБОРУДОВАНИЕ» + число + второй факт шире бюджета | на вывеске — имя здания, число с единицей, второй факт; имя раздела живёт в кнопках и меню |
| «Списком» не входит в цель 56×56 при 13 px | 53 px текста + поля | на телефоне «Список» под значком |
| `EdgesGeometry` на скруглённых кубах — ноль линий либо частокол | у `RoundedBoxGeometry` нет острых рёбер | контур «Контура» — своя линия по середине скругления + силуэт задними гранями |
| Ось насыщенности работает неровно (в `night` не видна, в `roofs`/`duo` крыши расходятся в бордовый и розовый) | нейтраль берётся по роли из `white`, у плит и объёмов крыши она разная | если прораб оставит ось — общая нейтраль для крыш; иначе ось убрать |
