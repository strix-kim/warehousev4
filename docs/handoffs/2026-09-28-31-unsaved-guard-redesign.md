## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| `useBlocker` бросает «must be used within a data router» | Под `BrowserRouter` блокировки нет вовсе | Data router, splat-маршрут; `App` с `<Routes>` не трогать |
| «Закрыть без сохранения» не закрывает дровер оборудования, карточка открывается снова | Закрытие = `setParams`; роутер спрашивает блокер синхронно, `activeRef` ещё `true` | `bypass(action)` — защита снята на время вызова |
| Фокус с «Продолжить правку» теряется при клике по подложке | Плашка монтируется до default-действия `mousedown` | `preventDefault` на `mousedown` подложки |
| `beforeunload` вместо плашки на «назад» в Playwright | Предыдущая запись истории от прошлого `goto` — уход с документа | Артефакт теста: переходы внутри приложения — ссылками |
| Playwright «Browser is already in use» | Chrome прошлой сессии держит профиль; `kill` классификатор автомода запретил | Прораб закрыл окно сам |
| `AppSelect` закрывается от Playwright-клика | Прокрутка к кнопке закрывает поповер — это A-01 аудита | Открывать после `scrollIntoView` одним `evaluate` |
