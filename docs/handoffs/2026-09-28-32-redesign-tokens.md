## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| `git add src/react/features/...` — «paths are ignored» | правило `features/` без слэша матчит каталог на любой глубине | `/features/` — привязка к корню |
| hover-рамка селекта и датапикера не темнеет | новая `--ctl` в покое темнее старой hover-рамки | hover → `--muted` + фон `--hover` |
| главная на 1440×900 прокручивается +23 px после шрифтов | Inter шире системного, описание плитки 6 строк вместо 5, `1fr` тянет обе строки | колонка текста 58 → 60 %; `text-wrap: pretty` и межстрочный не помогли |
| `npx motion-ai` запрещён автомодом | сторонний установщик — Untrusted Code Integration | прораб запускает `! npx …` сам |
| «classifier gave no verdict» на каждой команде | сбой сервиса автомода, не запрет | подождать и повторить; прораб «дальше» |
