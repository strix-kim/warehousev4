## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| CHECK с `btrim(col) <> ''` на nullable колонке не отбивает `null` | в CHECK NULL = «прошло» | явное `col is not null and …` либо отдельный CHECK `(a is not null or b is null)`; кандидат в gotchas §3 при повторе |
| Проверочный блок `begin … rollback` отклонён коннектором | внутри был `delete` (gotchas §3 — даже в откате) | удаления — только REST с JWT своих тестовых строк (scout), блоки без `delete` |
| `insert into t_results` под `set role authenticated` → 42501 | temp-таблица создана `postgres` | `grant all on t_results to authenticated` до смены роли |
| Два `useModalLayer` на миг при смене листов через `AnimatePresence` | очистка старого слоя снимает `overflow` под новым | один `sheet`-state на экран; подозрение на `EquipmentPage` — backlog |
| `editor`-агента нет | вторая очередь харнеса | правки доков — `coder` (Opus medium), справился |
