## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| «Удалить зал?» не нажимался у прораба | Safari: mousedown не фокусирует кнопку, но блюрит её саму (autoFocus) — onBlur гасил взвод до click | `onMouseDown preventDefault`; та же мина была у строки и плана; правило → gotchas §6 |
| Кодер-субагент завис (Ш2), второй умер на API-ошибке (Ш3) | стрим-вотчдог 600 с / обрыв потока — инфраструктура, не бриф | наработанное живёт на диске: `git status`, дифф глазами, остаток доделал ведущий; статус живого агента — `ListAgents`, пинг — `SendMessage` |
| Поллинг ТВ перетирал бы правку, сделанную на самом ТВ | refetch приезжает без ещё не сохранённого назначения | `silentRefresh` пропускает тик при `pending > 0 || addingCell`; отказ тика не валит экран — жёлтое «Нет связи» |
| Пикер не появился бы в fullscreen | браузер рисует только поддерево `fullscreenElement`, портал в body невидим | цель портала `document.fullscreenElement ?? document.body` (найдено кодером) |
| Удаление сотрудника, занятого в плане, упало бы невнятной ошибкой | FK был `on delete set null` при NOT NULL (с20), с CHECK-ом слота стало бы ещё хуже | FK → `on delete cascade`: планы — черновики, ячейки ушедшего освобождаются |
