## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Кампус в верхней половине кадра, дорога срезана | ограничитель цели двигал и камеру | цель скользит вдоль луча взгляда; искать причину, не подбирать числа |
| Клик по зданию приглушённой зоны уводил в раздел | цели указателя собирались до расстановки зон | `collectPicks` внутри `buildMap`, перед зонами |
| «Плюс» поверх панели места | `CSS2DRenderer` пишет `z-index` по дальности, у слоя не было контекста наложения | `.w-labels { z-index: 0 }` — подписи всегда ниже обвязки |
| Три кодера сдали зоны, не открыв браузер | браузер один на всех | заход «сведение» одним кодером с браузером — закладывать в план сразу |
| Основа зон дала брифы последователям | контракт писал тот, кто видел код | большой шаг: основа + готовые брифы → параллель → сведение |
| `git add -u` отклонён хуком | хук требует имена файлов | список из `git status --short` подстановкой |
| uz-дата «M10 7» | Intl для `uz` | `formatDayMonth`/`formatDayRange` в `lib/date.ts` на своём списке месяцев |
| Число строк источника ≠ число штук | `equipment` 1471 строка, штук 1867 (`sum(count)`) | на вывеске и плитке — штуки из `home_summary` |
