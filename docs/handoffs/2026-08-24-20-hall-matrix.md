## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Все фото стопкой в углу на iPhone, Excel — норм | QuickLook читает готовый `a:xfrm`, Excel — якорь `xdr:from`; мы писали в xfrm нули | генератор считает абсолютные EMU (суммы ширин/высот — константы листа); проверка причин — сравнение с файлом, сохранённым Excel |
| Двойники «имя 2/3/4.ext» пачками на каждый коммит | репо лежало в `~/Documents` под iCloud Desktop&Documents | переименование в `*.nosync` + симлинк со старым именем; память обновлена |
| «План не открывается, удаление молчит» после миграции | dev-сервер не перезапущен после переезда папки: браузер гонял СТАРЫЙ бандл в снесённую таблицу (404 в edge-логах) | диагноз по логам, не по коду; после переезда каталога — перезапуск dev обязателен |
| Дизайн редактора переделан трижды | проектировал по брифу со слов; настоящий образец прораб принёс после второй версии | образец «как делаете сейчас» выпрашивать ДО проектирования, даже если «образца нет» — фото старой таблицы меняет архитектуру |
| Чипы засева в случайном порядке | пачечный insert: одинаковый `created_at`, добивка по uuid | лесенка `created_at` миграцией; людские позиции с `now()` всегда после засеянных |
| Порядок правок прораба голосом | «продолжай»-семантика в midturn-сообщениях, части приходят отдельными фразами | не коммитить между фразами одной мысли; сводный чеклист после волны правок |
