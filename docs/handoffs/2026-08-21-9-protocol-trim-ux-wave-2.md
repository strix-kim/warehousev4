в двойном чтении: Fable читает исходники, чтобы написать бриф, coder читает их же,
чтобы исполнить. Отсюда и решение п. 2 — дешёвая сессия, дорогой архитектор по вызову.

## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Формула `100dvh − 409px` режет футер при любом баннере над сеткой | константа описывает ОДНО состояние страницы, а над сеткой стоят баннеры и раскрываемая панель | мерить: `useEditorChrome` складывает `offsetTop` по цепочке `offsetParent` + нижний отступ `.app-content`, пишет в CSS-переменную |
| `getBoundingClientRect` дал бы неверный отступ | у `.data-panel`/`.editor-grid` анимация `rise-in` с `transform` и `fill-mode: both` — на первом кадре прямоугольник сдвинут | цепочка `offsetTop`: она не видит `transform` |
| Потенциальная петля ResizeObserver | замер меняет высоту сетки → высота документа пересекает порог скроллбара → меняется ширина соседей → снова замер | писать переменную только при изменении значения |
| Требование «заполните реквизиты» исчезает с экрана невыполненным | поля с подсветкой размонтированы, пока полоса свёрнута | модификатор `--invalid` на самой полосе: красная рамка, красные пустые значения, подпись «Заполнить» |
| Подсказка про сборку списка стала недостижимой | `.quick-list-hint` лежала внутри блока полей, то есть показывалась только тому, кто открыл реквизиты | удалена: тот же смысл несут подзаголовок «Рабочий список» и пустое состояние панели |
| Одна дата в двух форматах на одном экране | `AppDatePicker` обходит Intl своим узбекским списком месяцев, полоса звала Intl напрямую | `formatEventDate` и `formatMonthTitle` вынесены в `lib/date.ts`, оба места зовут их |
| `aria-controls` указывает в пустоту | контейнер полей рендерится только в раскрытом состоянии | атрибут снят, `aria-expanded` на кнопке достаточно |
| Ритуал старта стоил 3 MCP-вызова и 5 команд каждую сессию | проверялось то, что и так падает само (мост, `node_modules`, `.env`) | проверки сняты; «мост слеп» диагностируется первым рабочим вызовом |
| Якоря `файл:строка` в библии протухают каждым коммитом | адресный дрейф не виден при чтении, в отличие от смыслового | ссылки только именем файла и функции; `/doc-audit` — по поводу, а не по расписанию |
