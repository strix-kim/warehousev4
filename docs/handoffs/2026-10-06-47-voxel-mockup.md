## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| «Детализируй здания» → прораб: «стали как настоящие, нужны миниатюры»; «сделай миниатюры» → «ты просто убрал детали, склад всё равно огромный» | три разных оси: количество деталей, архитектурный жест, габариты; я решал по одной за проход | у 3D-облика спрашивать все три сразу: силуэт, плотность деталей, масштаб относительно эталона (офис) |
| Playwright не открывает `file://` | политика MCP | стенд `http.server` из папки макета; кэш — `?r=` |
| Два агента в одном браузере Playwright путали вкладки | браузер — единоличный ресурс (current-state) | второму агенту — только файлы без браузера, либо ждать |
| Ответ `home_summary()` через MCP — ошибка членства | RPC проверяет `auth.uid()` | числа брать прямыми `SELECT`, RPC — только из клиента с JWT |
| `--night` на зданиях «тяжёлый» | чистый чёрный мира спорит с чёрным хрома | в сцене графит `--night-3`, чёрный только в HTML-UI (записано в `three.md`) |
