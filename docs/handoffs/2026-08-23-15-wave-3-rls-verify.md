## Грабли и решения

| Симптом | Причина | Решение |
|---|---|---|
| Мост отвечает «permission denied» на любую запись | коннектор Supabase переподключён с галочкой Read-only; признак — `select current_user` = `supabase_read_only_user` | переподключить коннектор без галочки; проверка — `current_user` = `postgres` |
| `create or replace` падает на RPC при смене типа возврата | Postgres не меняет return type существующей функции | `drop function` + `create`, гранты выставить заново; клиент учат обоим форматам ДО миграции |
| Гонка двух вкладок на вставке серийника | UNIQUE поставить нельзя (11 живых дублей) | `pg_advisory_xact_lock(hashtextextended(lower(сер), 0))` в RPC, локи в отсортированном порядке — иначе две партии с пересечением ловят deadlock |
| Пустой тестовый список нельзя переименовать document-RPC | `update_equipment_list_document` требует ≥1 позиции | для rls-прогонов создавать СВОИ списки с позицией, не трогать пустые ТЕСТ-с10 |
| iCloud наплодил двойников трижды за сессию | синхронизация | `diff -q` + `rm`; проверять `git status` перед КАЖДЫМ `git add`, не только на старте |
