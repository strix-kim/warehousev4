## Курс

**ARGO Warehouse** — внутренняя система ARGO Media. Ядро: списки оборудования на
мероприятие + Excel. Расширение: сотрудники (с17), автомобили (с18), экспорт «на
мероприятие» (с19), залы (с20–с22), калькулятор задержки излучателей ITC (с30).
**Текущая фаза: качество.** Аудит с30 нашёл 60 находок (UX, WCAG, вёрстка) —
прораб: **чиним всё**. Список по пакетам — `docs/project/audit-s30.md`. **Волна 1 закрыта в с31.**
Идёт **редизайн** по макету с31 (https://claude.ai/artifact/Tr8jMukVgSULsnfDBcpE48,
исходник `docs/project/design/redesign-s31.html`; прораб ответил «да» на все 6 вопросов).
**Основа сделана в с32:** палитра, шрифты (Inter/Manrope/JetBrains Mono у себя), веса,
радиусы, тени на токенах; «Контраст и фокус» аудита закрыт. Дальше — оболочка и экраны.

- **Репозиторий:** `github.com/strix-kim/warehousev4`, `main` = прод. Публичный.
- **Код:** `src/react` — 116 файлов, 21 004 строки (в ветке с32) + 7 woff2. **За порогом ~800:**
  `database.types.ts` 1057 (генерируется + правки руками, не пилим),
  `ListEditorPage.tsx` 813. Ближайшие: `05-features.css` 671, `EquipmentPage.tsx` 606,
  `EquipmentDrawer.tsx` 568. Роутер — data router (с31, канон в `canons.md`).
- **Стек:** React 19 + TypeScript 5.9 + Vite 7 + Supabase + Vercel; Node 22.x. Пять
  рантайм-зависимостей, без UI-кита, state-менеджера и react-query. Свой OOXML.
- **Локально:** `npm run dev` → `http://localhost:5180/` (strictPort).
- **Данные прода** (с22, перепроверено с26): `equipment` 1482 (218 моделей;
  1432 серийных, 46 со штампом импорта, 4 без кода), `employees` 12 (сроки пусты у
  всех, паспорта заполнены у всех), `vehicles` 6, **`vehicle_files` пуста**,
  `equipment_lists` 5 (4 мусорных `ТЕСТ-с10-*`), залы: 1 план (6 залов), `position_catalog`
  6, `users` 2 — оба `technician`, второй — `rls-test@argomedia.uz` / `technik2026`.
  Схема: **17 таблиц, 62 политики public + 4 storage, 21 триггер, 61 индекс**

- **xlsx для Windows Excel** выкачен в с29 без проверки в самом Excel; запись с19 «документы
