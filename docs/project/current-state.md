### Язык системы (с25) — снят с `equipment`/`lists`, не выдуман

- **Жанр выбирает единица данных.** Таблица — «сравнить много одинаковых по
  колонкам» (сотрудники, машины). Карточка — «узнать свою работу и что-то с ней
  сделать» (списки, планы залов). Третьего жанра не заводим; специальная сетка —
  только там, где данные двумерны (матрица залов).
- **Счётчик отвечает на ОДИН вопрос и печатается в ОДНОМ месте:** без фильтра
  «Сущность: всего», с фильтром «Найдено: видно из всего». Никакой другой контрол
  своего числа не печатает — два счётчика рядом расходятся в глазах.
- **У картинки три роли, четвёртой не нужно:** предмет в строке (это ДАННЫЕ),
  пустое состояние раздела, плитка главной.
- **Загрузка при пустом экране — скелет формы контента, никогда не текст.**
  Текстовых заглушек в трёх новых модулях не осталось (с25).
- **ТВ — отдельный жанр по построению.** Общий язык применяется одним правилом:
  всё на витрине читается с того же расстояния, что доска. Домовые `.data-panel`,
  `.state-block`, `.button` на витрину не тащим.
- **Кегль доски ТВ — одна формула на всех** (с21, подтверждено с25). Ужимать
  кегль под длину имени пробовали и отказались: доска читается как список равных,
  разный кегль назначает важность, которой нет. Не влезает — переносится БЕЙДЖ,
  имя остаётся целым.
- **Резерв полосы под арт завязан на его наличие** (`:has`, с25), а не на имя
  плитки: правило вернётся само, когда появится `<img>`.

### Стили (с25)

- **`styles.css` — баррель из шести `@import`, и порядок в нём работающий код,
  а не стилистика.** У медиазапросов та же специфичность, побеждает последний,
  поэтому `06-responsive.css` обязан идти замыкающим.
- **Локальные `@media` внутри блоков (520, hover, reduced-motion) остаются на
  местах.** Сводить все медиа в один файл нельзя — переставит каскад.
- **Распил делается чистым переносом и проверяется инвариантом:** конкатенация
  кусков побайтово равна исходнику, собранный CSS не меняется ни на байт.
- **Разделители сетки карточек рисуют сами карточки тенью,** а не подложка
  контейнера под зазором: подложка видна в незанятых ячейках, и неполный ряд
  давал серый прямоугольник до края панели.
- **Общие правила (`.list-card`, `.data-table`, `.state-block`) не переписываем —
  расширяем модификатором.**

### Тексты и числа

- **Тексты интерфейса — только `tr(ru, uz)`.**
- **Своего словаря окончаний не ведём** (`lib/date.ts`, `formatAge`): склонения
  отдаём `Intl`. Где склонение неизбежно — набираем форму «метка: число»
  («Операторы: 1»), которая не склоняется. Так подписаны и сводка плана, и ТВ.
- **Даты на `uz` печатаются в ISO** — свойство `Intl` для этой локали, не
  регрессия; вопрос продуктовый, в backlog.

### Проверки

- **Разделение проверок (с24):** механический прогон — работа агента через
  Playwright; вкусовая приёмка «красиво/понятно» — прораба.
- **Проверка без контроля чувствительности не проверка (с24).** Прежде чем
  верить «совпало», сломай образец нарочно и убедись, что метод это видит.
- **Пиксельное сравнение скриншотов — не судья** для страниц с ленивыми
  картинками и временем на экране (с25): расходится само по себе. Годится там,
  где ленивого контента нет (матрица дала побайтовое совпадение). Для каскада
  надёжнее сравнение собранного CSS и замеры `getComputedStyle`.
- **Мерить, а не подбирать (с25).** «Александр» на ТВ рвался не из-за длины —
  ширину съедал бейдж `×2`; замер `canvas.measureText` показал это за один вызов.
- **Гипотеза из чтения кода — не факт (с24).** Для ВИЗУАЛЬНОЙ задачи планировщику
  скриншоты нужны ДО выводов (с25): серый прямоугольник в сетке он не увидел,
  разобрав весь CSS.
- **Упавший агент воркфлоу оставляет правки частичными** (с25). Гейты после
  воркфлоу обязательны — они это и ловят. Вслепую не перезапускать: смотреть, что
  легло на диск, и дописывать по образцу успешного соседа.
- **Перф-находку без объёма данных не принимать (с23).**
- **Аудит отвечает на тот вопрос, который ему задали (с23).**
- **Возражение агента против плана ведущего — не шум (с23).**
- **Права — `/rls-verify`;** RPC и Storage — smoke curl-ом.
