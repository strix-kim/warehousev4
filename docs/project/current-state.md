## Каноны

- **База авторитетна.** Правило только в React — не существует.
- **`main` — прод; сливаем принятое** с зелёными `npm run check` и `npm run build`.
- **Тиры (с18): ведущего выбирает прораб**; код — `coder` (Opus), планы —
  `planner` (Fable), механика — `scout` (Sonnet). Раскладку называть перед
  воркфлоу.
- **Залы — матрица (с20):** позиции — строки ВСЕГО мероприятия
  (`plan_positions`), залы — колонки, ячейка = максимум один человек (UNIQUE
  `hall_assignments_cell_key`); пустая ячейка и есть вакансия, записей-вакансий
  нет. Несколько операторов в зале = несколько строк «Операторы».
- **Справочник позиций (с20):** `position_catalog`, общий на всех; вписанная
  руками позиция сохраняется в него сама; FK из планов НЕТ намеренно — строка
  плана это снимок, удаление из справочника планы не трогает. Порядок чипов —
  лесенка `created_at` засева.
- **Staff-DELETE на всех таблицах залов** (решение прораба с20, отход от канона
  с17 «DELETE только на связку»): планирование — черновик, не реестр.
- **Один человек в нескольких ячейках — норма** (страховка на все залы);
  подсветка: скрепка = несколько позиций в ОДНОМ зале, ×N = по всему плану.
- **Роль позиции: подпись «Видеоинженер»** (значение в базе — `technician`);
  счётчики считают уникальных людей по роли их строк.
- **`git branch --show-current` перед `git add`; статус на двойники** — риск
  снят `.nosync` (с20), привычка остаётся до пары чистых сессий.
- **Схема — только миграциями.** Код в прод раньше схемы.
- **Фото в xlsx: якорь `oneCellAnchor` + АБСОЛЮТНЫЕ координаты в `a:xfrm`**
  (с19/с20): Excel читает якорь, QuickLook — xfrm; нули в xfrm = стопка фото в
  углу на iPhone.
- **Фото для документов — `employees.document_photo_id`** (с19), NULL →
  последнее загруженное (`pickDocumentPhoto`).
- **Язык документа ≠ язык интерфейса** (с19): RU/UZ в дровере экспорта, тексты —
  `docText`. **Новые стили xlsx — только в хвост `styles.ts`** (с19).
- **Руководитель для документов — константа `companyDirector`** (с19).
- **Госномер: канон в базе** (с18); **машина↔водитель — M2M** (с18);
  **сотрудники: уникальность по документам** (с17); **файлы — только
  добавление** (с17/с18).
- **Signed URL — только in-memory кэш** (с17); **фото ужимает клиент** (с17).
- **UX проектирует агент** (с17); **образец «как делаете сейчас» выпрашивать ДО
  проектирования** (с20) — бумажный образец прораба перевернул архитектуру залов.
- **Пачечный upsert/insert под RLS — `defaultToNull: false`** (с18).
- **Ошибки вставки разбирать по ИМЕНИ ограничения** (с14), код клиенту — из
  класса `PT` (с14); `.contains()` — тип значения (с14).
- **Состояние каталога — в адресе** (с11/с15); каталог модельный (с15);
  серийник опционален (с16).
- **Тексты интерфейса — только `tr(ru, uz)`.**
- **Права — `/rls-verify` под двумя аккаунтами;** RPC и Storage — smoke curl-ом
  под `rls-test`.
- **Порог входа в библию (с12):** только невосстановимое чтением `src/react`.
- **`security definer` в `private.*` цел** (с12); `revoke from public, anon` на
  каждой новой функции. **Роли `admin` в проде НЕТ** (с15).
- **`reservation_start`/`reservation_end` — дата мероприятия, не бронь.**
