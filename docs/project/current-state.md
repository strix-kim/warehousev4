## Каноны

- **База авторитетна.** Правило только в React — не существует.
- **`main` — прод; сливаем принятое** с зелёными `npm run check` и `npm run build`.
- **Тиры (с18): ведущего выбирает прораб**; код — `coder` (Opus), планы —
  `planner` (Fable), механика — `scout` (Sonnet). Раскладку называть перед
  воркфлоу. Упавший/зависший субагент — не паника: наработанное на диске,
  дифф глазами, остаток доделывает ведущий (с21).
- **Прогон прав без второго браузера (с22):** мост read-only, поэтому `/rls-verify`
  гоняется по живому REST прода настоящим JWT второго аккаунта. Политики и
  PostgREST те же, что видит браузер. Рецепт — gotchas §2.
- **`HTTP 200` + ноль строк = отказ политики,** а не успех (с22).
- **Залы — матрица (с20):** позиции — строки ВСЕГО мероприятия, залы — колонки,
  ячейка = максимум один человек ИЛИ слот «Наём» (UNIQUE `cell_key`); пустая
  ячейка и есть вакансия («не решено»), слот — «решено: берём внешнего» (с21).
- **Слот «Наём» (с21):** `is_external` + CHECK «(employee_id is null) =
  is_external»; кнопка — только в операторских строках (правило в UI, backlog);
  FK на employees — `on delete cascade` (черновики).
- **Имена в расстановке — «Имя Фамилия»** (`employeeDisplayName`, с21).
- **Залы — общий черновик staff (с20/с21, подтверждено прогоном с22):** изоляции
  между staff нет по замыслу; чтение — любой член приложения, запись и удаление —
  любой staff, включая чужие планы.
- **ТВ `/halls/:planId/tv` (с21) — инструмент планёрки:** назначение кликом,
  структура только в редакторе; поллинг 30 с через `silentRefresh`; портал
  пикера — `fullscreenElement ?? body`.
- **Печать матрицы (с22):** цвет зала — ЧЕРТА под именем, не заливка (фоны браузер
  печатает лишь при включённой фоновой графике); панель и шапка на печати —
  `display: contents`, иначе Chrome не рисует сетку вовсе; серые токены темнеют
  внутри `@media print`; поле сверху 14 мм. Проверять печать — только по самому
  PDF, скриншот врёт. Всё это — gotchas §14.
- **Текст для чата (с22):** по залам, а не матрицей; **без markdown** — Telegram
  не разбирает разметку во вставленном тексте.
- **`document.title` — владелец один** (`LanguageProvider`), страница называет
  себя через `useDocumentTitle` (с22): из заголовка браузер берёт колонтитул листа
  и имя файла при «Сохранить как PDF». Эффекты детей идут раньше родительских —
  поэтому страница не пишет `document.title` сама.
- **Директор не назначается на залы** (с21).
- **Safari: кнопка с `autoFocus` + `onBlur`-гашением обязана иметь
  `onMouseDown preventDefault`** (с21, gotchas §6).
- **Справочник позиций (с20):** общий на всех; FK из планов НЕТ намеренно (снимок).
- **Один человек в нескольких ячейках — норма**; скрепка = несколько позиций
  в ОДНОМ зале, ×N = по всему плану.
- **Роль позиции: иконка без подписи** (с21, подтверждено для печати в с22).
- **`git branch --show-current` перед `git add`** — привычка остаётся.
- **Схема — только миграциями.**
- **Фото в xlsx: якорь `oneCellAnchor` + АБСОЛЮТНЫЕ координаты в `a:xfrm`** (с19/с20).
- **Фото для документов — `employees.document_photo_id`** (с19), NULL →
  последнее загруженное.
- **Язык документа ≠ язык интерфейса** (с19); **новые стили xlsx — только в хвост
  `styles.ts`** (с19); **руководитель для документов — константа `companyDirector`** (с19).
- **Госномер: канон в базе** (с18); **машина↔водитель — M2M** (с18);
  **сотрудники: уникальность по документам** (с17); **файлы — только добавление** (с17/с18).
- **Signed URL — только in-memory кэш** (с17); **фото ужимает клиент** (с17).
- **UX проектирует агент** (с17); **образец «как делаете сейчас» выпрашивать ДО
  проектирования** (с20).
- **Пачечный upsert/insert под RLS — `defaultToNull: false`** (с18).
- **Ошибки вставки разбирать по ИМЕНИ ограничения** (с14), код клиенту — из
  класса `PT` (с14); `.contains()` — тип значения (с14).
- **Состояние каталога — в адресе** (с11/с15); каталог модельный (с15);
  серийник опционален (с16).
- **Тексты интерфейса — только `tr(ru, uz)`.**
- **Права — `/rls-verify`;** RPC и Storage — smoke curl-ом.
- **Порог входа в библию (с12):** только невосстановимое чтением `src/react`.
- **`security definer` в `private.*` цел** (с12); `revoke from public, anon` на
  каждой новой функции. **Роли `admin` в проде НЕТ** (с15).
- **`reservation_start`/`reservation_end` — дата мероприятия, не бронь.**

- **Печать рвётся на второй лист без повтора шапки залов** (>~17 строк на десяти

- **Права: не-staff роль (`video_engineer`) и DELETE чужой записи** живым запросом
  не испытаны (backlog). Остальное по залам прогнано в с22.
- **Удаление списков зашито на почту** в политике `equipment_lists`; из-за этого
  четыре `ТЕСТ-с10-*` в проде не убрались — сносить прорабу из интерфейса (backlog).
- Узбекские тексты (документы с19, залы с20–с22) — носителем не проверены.
- Фото на телефоне после фикса `a:xfrm` — перевыгрузка не подтверждена.
- `catalogState` в `useHallPlanEditor` пишется, но не читается.
- Удаление фото сотрудника — решение прораба не получено (с19, backlog).
- Дыры «клиенту не верим» (оборудование): brand/model в document-RPC, UNIQUE
  серийника, количество. Слот «Наём»: роль строки не проверяется базой (backlog).

  неотличим от ошибки полей; не-staff видит кнопки записи; signed URL живёт час
  у любого держателя (принято, с17).
- Схема vs репозиторий (с2): `users.id` без FK на `auth.users`; дубль FK на
  `mount_points`; `baseline.sql` не исполнялся на чистой базе. Auth не для
  внешнего запуска (пароли, патчи Postgres).
- Доступность: фокус-ловушек в дроверах нет; `AppSelect` не listbox; матрица и
  ТВ с клавиатуры не проходятся.
- `styles.css` 1132 и `ListEditorPage.tsx` 813 — за порогом; мёртвый
  `.quantity-stepper` в styles.css (backlog).
- Плитки «Автомобили» и «Залы» на главной без иллюстраций — арт за прорабом.
- Экспорта в дровере деталей нет (R-F9); мёртвые метки `issued`/`returned`;
  `features/` в корне — untracked каталог прораба.
