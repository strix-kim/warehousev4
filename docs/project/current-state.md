## Курс

**ARGO Warehouse** — внутренняя система ARGO Media. Ядро: списки оборудования на мероприятие + Excel.
Расширение: сотрудники (с17), автомобили (с18), экспорт «на мероприятие» (с19), залы (с20–с22), калькулятор
задержки ITC (с30), расходы (с51), мероприятие (с54), обеды (с57).
**Фаза: качество** (аудит с30 — `audit-s30.md`) **+ воксельный мир (с47) + новые разделы (с49).**
Редизайн по макету с31 (https://claude.ai/artifact/Tr8jMukVgSULsnfDBcpE48, исходник
`docs/project/design/redesign-s31.html`); сделано с32–с39, хроника в handoff этих сессий.
**Режим с34+ (прораб с33): экраны подряд без промежуточной приёмки**, машинные проверки и коммит авансом,
прораб смотрит итог один раз. **Машинные проверки — Sonnet-`scout` (прораб с45);** живые правки данных в
браузере скауту не даёт классификатор — они в чеклисте прорабу. Правки доков по списку — `coder` (editor-агента нет).
