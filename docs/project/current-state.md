## Каноны

- **База авторитетна.** Правило только в React — не существует.
- **`main` — прод; сливаем принятое** с зелёными `npm run check` и `npm run build`.
- **Тиры (с18): ведущего выбирает прораб**, модель сессии не задавать в
  `settings.json` и не переключать; код — `coder` (Opus), планы — `planner`
  (Fable), механика — `scout` (Sonnet). Раскладку называть перед воркфлоу.
- **`git branch --show-current` ПЕРЕД `git add`** (с11) и **`git status` на
  двойники iCloud перед КАЖДЫМ `git add`** (с15/с17: двойники приходят и в
  новые каталоги).
- **Схема — только миграциями.** Код в прод раньше схемы; смена типа возврата
  функции — `drop` + `create`, гранты заново.
- **Фото для документов — колонка `employees.document_photo_id`** (с19):
  составной FK `(id, document_photo_id) → employee_files(employee_id, id)`
  отбивает чужое фото (23503), триггер — скан вместо фото (23514); NULL →
  последнее загруженное, правило в одном месте — `pickDocumentPhoto`.
- **Язык документа ≠ язык интерфейса** (с19): RU/UZ выбирается в дровере
  экспорта, по умолчанию UZ; тексты документа — `docText`, не `tr`. Данные
  (должность, место рождения) печатаются как лежат в базе.
- **Фото в xlsx — `oneCellAnchor`, не `twoCellAnchor`** (с19): размер в EMU,
  Excel не растягивает до второй ячейки; contain в бокс 120×160 px без
  апскейла. Фото качаем `storage.download()` (Blob под JWT, без signed URL).
- **Новые стили xlsx — только в хвост `styles.ts`** (с19): индексы xf 0–20
  держат экспорт оборудования побайтно; проверка переноса — snapshot с
  подменённым `Date` (рецепт в handoff с19).
- **Руководитель для документов — константа `companyDirector`** (с19, отмена
  с18): реквизит фирмы, не производное от `employees.position`.
- **Госномер: канон в базе** (с18): хранится «как на жестянке», BEFORE-триггер
  нормализует (upper, схлопнуть пробелы, кириллические двойники → латиница),
  уникальность — функциональный индекс по номеру без пробелов
  `vehicles_plate_number_key`; клиент шлёт как ввели, без пре-чеков.
- **Связь машина↔водитель — M2M** (с18): массив uuid запрещён (нет FK на
  элементы); staff имеет DELETE на `vehicle_drivers` — единственный DELETE-грант
  рядовой роли, только на связку, не на данные.
- **Сотрудники: уникальность — по документам** (с17): UNIQUE по ПИНФЛ и паре
  серия+номер, тёзки легальны — форма предупреждает, база пропускает.
- **Файлы сотрудников и машин: только добавление** (с17/с18): UPDATE/DELETE нет
  ни в политиках бакетов, ни в грантах таблиц; прямой `delete from
  storage.objects` запрещён Supabase — только Storage API (временная политика).
- **Signed URL не кэшируется дольше сессии** (с17): только in-memory через
  `createSignedUrlCache(bucket)`, TTL час, запас 5 минут.
- **Фото ужимает клиент до 1600px** (с17, общий `lib/compressPhoto.ts`).
- **UX проектирует агент** (мандат прораба, с17): мерило — рядовой сотрудник без
  обучения; готовые решения на приёмку, а не вопросы «как сделать».
- **Пачечный upsert под RLS — `defaultToNull: false`** (с18): иначе postgrest-js
  шлёт NULL в непереданный `created_by` и строка отлетает по политике.
- **Код ошибки для клиента — из класса `PT`, не 40** (с14); ошибки вставки
  разбирать по ИМЕНИ ограничения, не по коду.
- **`.contains()` в postgrest-js смотрит на тип ЗНАЧЕНИЯ** (с14): jsonb — строкой.
- **Гонку уникальности без UNIQUE-индекса закрывает `pg_advisory_xact_lock`**
  (с15/с16); у сотрудников и машин гонки закрыты самими UNIQUE-индексами.
- **`CASCADE` на политике RLS — не выход** (с10).
- **Необратимое объявляется и исполняется тем же ходом.** Каждая
  `create/replace function` — с `revoke from public, anon`.
- **`revoke all on public.users` держится на `security definer`** (`03-data-model`).
- **Роли `admin` в проде НЕТ** (с15): оба аккаунта `technician`; удаление
  сотрудников, машин и файлов недоступно через клиента — только мостом.
- **`reservation_start` / `reservation_end` — ДАТА МЕРОПРИЯТИЯ, не бронь.**
- **Состояние каталога — в адресе** (с11/с15); карточки: `?employee=<id>`,
  `?vehicle=<id>` (открытие push, закрытие replace).
- **Каталог модельный** (с15); **серийник — опциональный атрибут** (с16);
  **переход между открытыми дроверами без повторной анимации** (с16).
- **Ячейку-константу на телефоне убирают ИЗ DOM** (с11).
- **Значения в `.or(...)` PostgREST квотируются** после `escapeLikePattern`.
- **Тексты интерфейса — только `tr(ru, uz)`.**
- **Права — прогон под двумя аккаунтами** (`/rls-verify`); RPC и Storage мостом
  не проверить (`auth.uid()` пуст) — smoke curl-ом под `rls-test` (с16–с18).
- **Порог входа в библию (с12):** только невосстановимое чтением `src/react`.
- **`security definer` в `private.*` цел** (с12). **Протокол с9 сокращён.**

## Долги

- **Приёмка глазами — шесть слоёв** (см. шапку); браузерные половины
  `/rls-verify` с17 и с18 не гонялись (curl-половины доказаны); **выгрузка с
  фото в Excel не открывалась** — единственный реальный риск с19.
- **Узбекские тексты документов** (заголовки, шапки, период) — носителем не
  проверены.
- **Удаление фото сотрудника** — прораб заметил отсутствие (с19); закрыто
  намеренно в с17, решение открывать/нет не получено (backlog).
- **Седьмая тестовая машина**: появится, когда прораб/сотрудник прогонит пункт 5
  чеклиста с18 (создание с фото) — убрать мостом после приёмки.
- **Дыры «клиенту не верим» (остаток, только оборудование):** brand/model
  позиций в document-RPC из клиентского JSON; UNIQUE серийника нет; количество
  не сверяется с остатком. У сотрудников и машин дыр этого класса нет.
- **Сирота в бакете** (с17, теперь и `vehicle-files`): упавшая вторая ступень
  загрузки оставит объект без строки; убирать — дашбордом. Развилка: Edge
  Function или периодическая сверка.
- **Отказ RLS на update неотличим от ошибки полей** (сотрудники и машины,
  PGRST116 → общий текст); разбирать, когда роли реально начнут ограничивать.
- **Не-staff видит кнопки записи** — клиент не знает роли; прятать = доставить
  роль на клиент (claim/RPC) — отдельное решение.
- **Живой signed URL работает у любого держателя до истечения часа** — принято
  для внутренней системы (с17).
- **Схема vs репозиторий (с2):** `users.id` без FK на `auth.users`; удаление
  списков по почте вместо роли; дубль FK + четыре триггера на `mount_points`;
  неиспользуемый GIN-индекс. `baseline.sql` ни разу не исполнялся на чистой базе.
- **Auth не для внешнего запуска:** пароль А из шести нулей, пароль Б в доках
  открытым текстом, защита от скомпрометированных паролей выключена, Postgres
  без свежих патчей. (Регистрация закрыта в с17.)
- **Доступность:** фокус-ловушек в drawer'ах нет (видов уже ПЯТЬ: единица,
  модель, списки, сотрудник, машина); `AppSelect` не выполняет контракт listbox.
- **`styles.css` 1120 и `ListEditorPage.tsx` 813 — за порогом**; кандидаты — в
  `backlog.md`.
- Строка «Черновик · сохранён …» после перезагрузки показывает время создания.
- Экспорта в дровере деталей нет (R-F9); глубокие ссылки `?item=`/`?mbrand=`
  живьём не проверены (с15).
- `features/` в корне — untracked каталог прораба (xlsx/docx, источник импортов
  с17–с18); `.gitignore` или унести.
- Мёртвые метки `issued`/`returned` в журнале движений; триггер журнала не
  пишет INSERT единицы (с16).
- Плитка «Автомобили» на главной без иллюстрации — арт серии за прорабом,
