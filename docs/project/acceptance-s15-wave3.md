# Приёмка с15 — волна 3 (отложенные визуальные проверки)

Код всех трёх пунктов волны 3 выкачен в прод и принят прорабом авансом в с15;
операционная сторона доказана живыми вызовами RPC и прогоном `/rls-verify`
(вердикты — в handoff с15). Здесь — то, что проверяется ТОЛЬКО глазами.
Прогонять на проде `warehouse.argomedia.uz`.

## U35-б «Добавить в список» — принят в с15, прораб проверил руками

Оставлено для регресса при случае: секция «В список» в карточке единицы,
«Добавлено — теперь N шт.» у количественных, «× N» в «Сейчас в списках».

## U34-L Партия серийников — НЕ смотрено глазами

1. Заведение → «Способ учёта» — теперь ТРИ карточки; выбрать «Партия с
   серийными номерами».
2. Textarea «по одному в строке»: три выдуманных номера → подсказка
   «Распознано номеров: 3», поле «Количество» показывает 3.
3. Один номер дважды → красная подсказка «Повторяются: …», кнопка гаснет.
4. Живой номер из каталога в партии → сохранить → красное сообщение с
   перечнем занятых, ничего не сохранено (проверить каталогом).
5. Чистые номера → «Добавлено единиц: 3»; в каталоге у модели +3 штуки.
6. Тестовые записи после проверки удалить (клиент удалять единицы не умеет —
   сказать агенту, снесёт запросом).

## U29 Каталог моделей — НЕ смотрено глазами

1. Каталог: строка — модель; счётчик «Моделей: 218 · штук: 1 877»; на телефоне
   ~28 нажатий «показать ещё» вместо 186 страниц.
2. «Доступно: 0» у модели — красный бейдж.
3. Клик по ITC TS‑0370HD → дровер: бейджи сводки, 596 единиц списком.
4. Клик по единице → карточка; «назад» шагает карточка → модель → каталог.
5. Поиск серийника (`AH00001EK23A0296`) → одна модель ITC; серийники в
   выдаче моделей больше не видны — это ожидаемая цена агрегата.
6. Правка статуса единицы из карточки → в дровере модели и в колонке
   «Доступно» число изменилось без перезагрузки.
7. Фильтры категории/подкатегории/статуса работают по моделям; мобильная
   карточка прячет «Штук: 1» и «доступно = всего».

## Тексты отказов (`/rls-verify` с15: операции доказаны, тексты — нет)

Аккаунт Б: `rls-test@argomedia.uz` / `technik2026`, ТОЛЬКО приватное окно.

1. Б удаляет чужой список → человеческое сообщение об отказе прав, не пустой
   экран и не «попробуйте ещё раз».
2. Конфликт версий (карточка в двух окнах, А сохранил первым) → у Б сообщение
   «карточку уже изменили…», введённое не стёрто, повтор проходит.
3. Б без строки в `users` (сказать агенту — уберёт и вернёт строку) →
   «Каталог пуст или недоступен», не белый экран.
