# Старт сессии

Правила (ветки, прод, мост, схема) — `docs/system/workflow.md`. Здесь — только
последовательность. Протокол этого проекта сокращён в с9 решением прораба: доку
читает только агент, поэтому всё, что дублирует git или ловится первым же рабочим
вызовом, из ритуала снято.

## Шаги

1. **Контекст.** Прочитай `docs/project/current-state.md` целиком, затем handoff
   по строке «**Актуальный handoff:**». Указателя нет → файл с НАИБОЛЬШИМ номером
   сессии `N` в имени (`YYYY-MM-DD-N-…`); лексической сортировке не верь (`9` > `10`).
   Нет ни current-state, ни хэндоффов → первая сессия проекта: предложи болванку
   `docs/system/product-doc-guide.md`, код до неё не пишем.

2. **Git.**
   ```bash
   git log -5 --format="%h %ci %s"
   git status --short
   git branch --show-current
   ```
   - Незакоммиченные правки при чистом закрытии прошлой сессии → либо живая
     параллельная сессия (спроси прораба, чужое не коммитим), либо обрыв →
     аварийное восстановление ниже.
   - Двойники «имя 2.ext» от синхронизации → `diff -q` с оригиналом, удалить явным
     списком (gotchas §10).
   - `main` — прод. Прошлая ветка влита → `git switch -c session-N-тема` от `main`
     до первой правки; имя можно сменить, когда цель согласована.

3. **Следующий шаг** из handoff и «Очередь целей» из current-state (№1 — кандидат
   в цель). Шаг начинается с проверки («убедиться, что миграция доехала») → выполни
   её сейчас и доложи результат.

4. **Цель сессии** — одно проверяемое предложение («редактор сохраняет смешанный
   состав», не «поработать над списками») плюс сводка пунктов 1–3 в 5–8 строк.
   Без согласованной цели код не пишем; цель прораба приоритетна.

## Чего на старте НЕ делаем (снято в с9)

- **Не проверяем мост** (`list_projects` Supabase/Vercel). Мост не падал с с2;
  если первый рабочий вызов вернёт «проекта нет» — скажи «мост слеп» одной строкой
  и работай по коду. Выдумывать факты о живой базе запрещено всегда.
- **Не проверяем `node_modules` и `.env`** — без них `npm run dev`/`build` падают
  сами, явным текстом.
- **Не считаем сессии до `/doc-audit`** — он по команде прораба или перед вехой.

## Аварийное восстановление (сессия оборвалась без хэндоффа)

1. `git log -5`, `git status`, `git branch --show-current`, current-state —
   восстанови картину: что закоммичено, что висит, в какой ветке.
2. Короткий handoff задним числом (что удалось установить).
3. Цель согласуй заново — старую вслепую не продолжай.

## Грабли

- Указатель «Актуальный handoff» ведёт на несуществующий файл → бери максимальный
  `N` и скажи прорабу.
- `docs/handoffs/` никогда не чистим — это история проекта.
- Всё в `src/` — живой код (легаси-Vue удалён в с4); фильтровать `git status` не надо.
